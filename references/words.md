# Word tables

Lookup tables for the rules in `SKILL.md`. None of these words is banned outright. Each is a flag: common in model output, rarer in human writing, and worth a second look when several appear together.

## Announcements and throat-clearing

Cut the phrase and state the point.

Let's dive in / let's explore / let's break this down / let's unpack / here's what you need to know / here's the thing / here's why that matters / now let's look at / before we get into / without further ado / a quick note / heads up / one thing worth flagging / it's worth noting that / it bears mentioning / as we'll see

## Flattery and chatbot residue

Cut without replacement.

Great question / excellent point / you're absolutely right / that's a really good catch / I hope this helps / hope that clarifies / let me know if / feel free to ask / would you like me to / want me to / should I continue / happy to expand / certainly / of course / absolutely / here is a / below you'll find

## Significance inflation

Claiming an ordinary fact carries weight.

marks a pivotal moment / represents a turning point / signals a shift / underscores the importance of / highlights the significance of / speaks to a broader / reflects a growing / stands as a testament / serves as a reminder / paved the way for / set the stage for / cemented its place / left an indelible mark / plays a crucial role / a defining feature of / in an evolving landscape

## Advertising register

Brochure words. Common in product, place, and company descriptions.

boasts / seamless / robust / powerful / cutting-edge / best-in-class / purpose-built / thoughtfully designed / carefully crafted / vibrant / rich (figurative) / stunning / breathtaking / nestled / in the heart of / a commitment to / dedicated to excellence / unparalleled / world-class / game-changing

## Stock vocabulary

Words models reach for at several times the human rate. One is nothing. Four in a paragraph is a signature.

delve / leverage (verb) / harness / unlock / elevate / streamline / foster / cultivate / navigate (figurative) / underscore / showcase / highlight (verb) / align with / resonate with / tapestry / landscape (abstract) / ecosystem (non-biological) / interplay / nuanced / intricate / multifaceted / holistic / crucial / pivotal / vital / key (adjective) / robust / comprehensive / seamless / actionable / meaningful / profound / compelling / testament / enduring / myriad

## Hedges

Keep at most one per claim, and only when the uncertainty is real.

perhaps / possibly / potentially / arguably / conceivably / it could be argued / one might say / to some extent / in some cases / more or less / relatively / fairly / somewhat / generally speaking / in many respects / it seems that / it appears that / tends to / may or may not

## Vague attributions

Name the source or cut the sentence. Do not invent a name.

experts say / experts believe / studies show / research suggests / data indicates / industry reports / analysts note / observers have pointed out / critics argue / some would say / it is widely believed / it is generally accepted / sources familiar with / a growing body of evidence

## Aphorism templates

Sayings that sound quotable and specify nothing. Replace with the concrete claim.

X is the Y of Z / X is not a tool but a mirror / X becomes a trap / the language of X / the currency of X / the architecture of X / X is a feature, not a bug / the real X is Y / where X meets Y / X at scale

## Abstract metaphor nouns

Plain word, in technical prose.

substrate / surface area / flywheel / north star / primitive / lever / vector (non-mathematical) / fabric / connective tissue / center of gravity / forcing function / step change / order of magnitude (when not literal)

## Adverbs that pad

Cut, or find a stronger verb. Keep any adverb that states a fact.

very / really / quite / rather / fairly / extremely / incredibly / remarkably / notably / significantly / substantially / considerably / particularly / especially / simply / merely / just / actually / basically / essentially / literally / clearly / obviously / certainly / undoubtedly / arguably / effectively / seamlessly / robustly / carefully / thoughtfully

## Hyphen pairs

Hyphenate before a noun, not after. *A data-driven report.* *The report is data driven.*

data-driven / cross-functional / client-facing / end-to-end / real-time / long-term / short-term / high-quality / well-known / decision-making / third-party / best-in-class / user-friendly / future-proof / battle-tested
